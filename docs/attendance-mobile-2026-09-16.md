# 考勤与移动端改进（2026-09-16）

## 使用方式

- 手机（760px 及以下）默认进入「按日登记」，桌面默认显示「月度总览」，可以手动切换。
- 按日登记支持日期选择、前后一天、姓名/工种搜索、状态筛选，直接点击上班、请假或未登记 / 休息即可保存。
- 卡片显示本月出勤和请假天数；保存过程中禁止重复提交，失败时保留原状态并提示重试。
- 月度总览保留原有分页、导入导出和人员配置，日期格子支持键盘 Enter / 空格操作。
- 「一键填报工作日」仅补录空白工作日，不覆盖已有请假或上班记录，不修改周末；重复执行不会重复新增。它是整月补录工具，不判断法定节假日。
- 修改考勤后，切换工资结算会刷新数据，并恢复所选结算页签。
- 手机主导航改为折叠菜单，优化触摸按钮、输入字号、表格滚动和弹窗可用高度。

## 验证

使用独立临时数据库和虚构人员，未连接或修改生产数据。

- 考勤、薪资、安全测试：29 项通过，包括补录保留请假、幂等性、排除非考勤人员及错误参数校验。
- 全量回归：170 项通过、4 项原有失败；JavaScript 语法检查及 Git diff 空白检查通过。
- 本地 Chrome 无头浏览器：320、375、390、768、1440px 考勤页无整页横向溢出。
- 实测 18 人按日名单（含超过矩阵分页人数）、姓名搜索、状态筛选、开启 CSRF 后保存、模拟 HTTP 500 失败恢复、工资页刷新及手机导航展开收起；没有 JavaScript 页面异常。

原版本 HEAD（febb570）的独立工作树同样存在以下 4 项测试失败，本次不改变相关业务：默认系统设置断言未覆盖新增 AI 配置、安全头断言与现行 SAMEORIGIN 不一致、其他模板遗留 emoji、损坏 PDF 的解析错误文案断言不一致。

## 范围

本次是本地代码改进，未发布到线上。考勤仍采用原有上班 / 请假 / 空白模型，空白兼容「未登记 / 休息」，未引入半天、加班、定位打卡或审批，也未调整计薪规则。
