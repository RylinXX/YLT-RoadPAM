# 全系统视觉改版

## 界面调整

统一样式位于 `construction_maintenance/static/workbench.css`，在公共基础样式和移动布局之后加载；登录页也使用同一套颜色和表单规范。

- 深色导航、浅灰背景、实色内容卡片和绿色主操作按钮；深色模式使用独立表面、边框及文字色。
- 导航按工作空间与业务管理分组，缩短菜单名称，分组改用原生按钮并提供展开状态。修正直接访问 `/attendance` 时人员菜单未激活的问题。
- 看板分离标题、常用操作和六项指标，增加项目台账与登记考勤入口。
- 统一模块标题、留白、卡片、表格、按钮、表单和弹窗。考勤上班状态增加勾选标识，不只依赖颜色。
- 平板保留带名称的导航，手机继续使用折叠菜单；宽表格在容器内滚动，修正资质卡片在 320px 视口中的溢出。
- 登录页面使用新版实际看板截图，截图来自独立演示数据库。
- 项目页删除写死的金额 `¥1,162.57万`，改为按实际项目状态统计进行中项目数。

## 验证

独立数据库及虚构人员、项目，不连接生产环境。Chrome 无头浏览器开启登录认证及 CSRF。

11 个主页面：看板、项目、人员、考勤、费用、合同、资质、录入、设置、费用分类、待补录费用。

- 上述页面在 320、390、768、1440px 下共 44 次检查，均返回 200，未发现整页横向溢出。
- 11 个主页面的桌面深色模式加载检查通过。
- 实测登录、主题切换、考勤保存、移动导航、分组展开及新增项目弹窗；无 JavaScript 页面异常。
- 全量 Python 回归维持 170 项通过和 4 项已在原版本复现的失败。登录图片引用测试同步更新为新资产。

截图预览位于工作区 `output/roadpam-redesign/index.html`，支持查看各页面桌面截图、手机效果与深色模式。
